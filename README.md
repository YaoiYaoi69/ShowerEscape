# ShowerEscape
Escape the shower.

## Run

Run the game with Python and Tkinter in a desktop environment with a graphical display:

```powershell
python game.py
```

If your system does not provide a display server, the game will exit cleanly instead of crashing with a Tkinter error.

Virtual-environment files are intentionally not committed. Create a local environment with `python -m venv .venv` if needed.
